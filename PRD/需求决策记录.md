# 山风风物志 MVP 需求决策记录

> 生效日期：2026-08-28。本文只记录已采用的方案；被放弃的备选方案已移除。

| ID | 决策 | 结论 |
|---|---|---|
| D-01 | MVP 交付 | 手机 H5 游客主链路为 P0；手机号登录、认领与网页同步为 P1。游客以服务端匿名 token 标识。 |
| D-02 | 采风输入 | 文字与图片为 P0；语音转写不进入两天 MVP。 |
| D-03 | 基础建档 | 品牌/公司名、所属产业、核心产品、产地均为必填；品牌名不可为空。 |
| D-04 | 档案入库 | 采风结束后逐张展示候选档案卡；用户“确认”后入档案，“弃用”则丢弃。采风中生成的笔记不可编辑。 |
| D-05 | 定调 | P0 输出两条路线、选择当前路线、可编辑文本和只读品牌手册；Logo/色彩由 AI 生图或已上传 Logo 自动提取，不做矢量编辑。 |
| D-06 | 观潮 | 按项目上下文真实检索公开网络，返回 2 张有来源灵感卡；无结果/失败显示“灵感正在积攒中”，不伪造实时结果。供应商能力从 `credits.openai-next.com` 资源清单中选用，预算上限为 500 美元。 |
| D-07 | 出山 | 用户先选“周边概念稿”或“小红书图文”模板，再生成相应的一套物料；可无素材生成纯文字或通用背景版本。 |
| D-08 | 游客额度 | 游客可建 1 个临时项目、搜索 1 次、生成 1 套物料；同项目可额外重新生成 1 次。登录认领后重置额度；未认领项目和临时文件 7 天后删除。 |
| D-09 | 用户与权限 | MVP 仅项目拥有者；不提供成员、协作或审核角色界面。 |
| D-10 | 隐私与素材 | 上传前必须同意隐私/素材授权；禁止输入或展示精确住址、身份证等敏感信息；项目删除时删除本地文件与派生物。当前演示素材未确认授权，公开演示只能使用自有、已获授权、去标识化或 AI 生成素材。 |

## 实施假设

- 预置品类和自定义产品均可在创建时选择；项目创建后可在项目设置修改。
- 公开网页的链接仅作为灵感/参考展示，不在 MVP 中建立复杂的事实置信度、风险等级或公开范围字段体系。
- 小红书图默认 3:4；若所选图像能力不支持该尺寸，界面应标示实际尺寸并允许下载。
