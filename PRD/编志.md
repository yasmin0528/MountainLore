# 编志模块 PRD

> 适用范围：山风风物志两天 MVP。与最终总规范保持一致：[山风风物志-MVP功能开发PRD.md](山风风物志-MVP功能开发PRD.md)。

## 1. 模块定位

编志是项目的档案编辑台：将已结束采风中产生的候选信息，由用户逐张确认后沉淀为可编辑、可继续累积的风物档案。它不是 CRM，也不替用户把零散叙述包装成确定事实。

## 2. 输入、输出与边界

| 项目 | 说明 |
|---|---|
| 输入 | 已完成采风 session 的 FieldNote、关联图片和对话素材。 |
| 输出 | 已确认的 ArchiveCard，供定调与出山使用。 |
| 采风边界 | 采风中的实时笔记不可编辑；只在结束 session 后进入候选确认。 |
| 定调边界 | 只读取已确认、未弃用的档案；不修改档案正文。 |

## 3. 流程

```text
结束采风 → 生成候选档案卡 → 用户逐张确认 / 弃用
→ 已确认卡进入档案列表 → 用户查看、编辑、新增或弃用
→ 已确认且未弃用卡可进入定调与出山
```

候选卡不能自动入库。点击“弃用”仅丢弃该候选卡，不删除原始采风笔记和素材。

## 4. 档案类型与卡片

MVP 类型：`PRODUCT` 产品、`PEOPLE` 人物、`ORIGIN` 产地、`PROCESS` 工艺/加工链、`LIFESTYLE` 地方生活方式、`MEMORY` 品牌记忆、`CLUE` 待核实线索。

每张卡显示：类型与编号、标题、正文、关联图片或网页链接、来源简述、创建时间及操作菜单。使用 Field Record / Archive Card 视觉规范：暖纸色、细暖灰边框、清晰 metadata 与图片说明，不使用彩色 SaaS 卡片。

## 5. 功能需求

1. 候选确认页按卡片展示本次 session 的候选内容，提供“确认”“弃用”和原始素材查看。
2. 档案列表按类型过滤、按更新时间排序；MVP 不做复杂实体消歧。标题与类型明显一致时可由模型建议合并，不确定则新建。
3. 详情页可编辑标题、正文、关联素材；保存后立即反映在列表与后续定调输入中。
4. 用户可新建空白档案卡；新建卡同样必须确认保存后才能被下游使用。
5. 弃用已确认卡时需二次确认；弃用后从定调/出山输入移除，但保留恢复能力直到项目删除。

## 6. 状态与验收

| 对象 | 状态 | 规则 |
|---|---|---|
| 候选卡 | pending / confirmed / discarded | 只有 confirmed 创建正式档案。 |
| 正式档案 | active / discarded | 只有 active 可被下游读取。 |

- 结束采风后，每张候选卡可独立确认或弃用。
- 弃用候选卡不得出现在档案列表、定调或出山中。
- 编辑和刷新后内容一致；关联素材可打开或明确显示已失效。
- 任何空列表都提供“暂无已确认档案”“返回采风补充”的明确状态。
